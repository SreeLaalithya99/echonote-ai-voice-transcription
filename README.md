# EchoNote – AI Voice Note Transcription Platform

EchoNote is a browser-based application that records voice notes and converts them into text
using AI transcription APIs and OCR technology. Accessibility features include text-to-speech playback.

---

## System Architecture

Browser Extension → Captured Voice Note → AI Transcription → Text Output → Dashboard

---

## Technologies Used

- Python (Backend transcription)
- OCR & Gemini API
- Browser Extension (JavaScript)
- Streamlit (Dashboard)
- Pandas

---

## Project Structure

data/ – sample audio notes  
app/ – transcription backend scripts  
extension/ – browser extension code  
docs/ – project documentation
